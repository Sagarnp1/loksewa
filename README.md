# SagLok — शाखा अधिकृत प्रथम पत्र तयारी मञ्च

लोक सेवा आयोगका **विगतका प्रश्नपत्र**मा आधारित शाखा अधिकृत (Section Officer) प्रथम पत्र — *प्रशासनिक अभिरुचि परीक्षण* को अनलाइन तयारी वेबसाइट।

---

## चलाउने तरिका (How to run)

आवश्यक: **Node.js** (कुनै अतिरिक्त प्याकेज चाहिँदैन)।

```bash
node server.js
```

त्यसपछि ब्राउजरमा खोल्नुहोस्: **http://localhost:8787**

> टिप्पणी: पृष्ठहरूले `fetch()` बाट JSON डाटा लोड गर्ने भएकाले फाइल सिधै `file://` बाट नखोली माथिको सर्भर मार्फत खोल्नुपर्छ।

## पृष्ठहरू (Pages)

| पृष्ठ | फाइल | विवरण |
|------|------|-------|
| **विश्लेषण** | `public/index.html` | खण्डगत भार, इकाईगत गहिरो विश्लेषण (आधा निःशुल्क → भुक्तानी), मुख्य निष्कर्ष, समय-योजना |
| **टपिकवार अभ्यास** | `public/practice.html` | इकाई अनुसार प्रश्न + विकल्प (PDF झैँ) + दायाँतिर सही उत्तर र व्याख्या |
| **मोडेल सेट** | `public/sets.html` | ५ सेट — पहिलो निःशुल्क, बाँकी भुक्तानी |
| **परीक्षा** | `public/test.html?set=SET1` | टाइमर, प्रश्न प्यालेट, **रफ पेपर**, बुझाएपछि रोल नम्बर + नतिजा + **२०% ऋणात्मक अंक** |

## मुख्य विशेषताहरू

- **प्रश्न विश्लेषण** — पाठ्यक्रमका ३ खण्ड, १४ इकाई; प्रत्येकमा उपविषय, प्रश्नका प्रकार (%), नमुना प्रश्न र रणनीति (`data/syllabus.json`)।
- **१७० विगतका प्रश्न** — नेपाली + अंग्रेजी, विकल्प, सही उत्तर र व्याख्यासहित; इकाई अनुसार वर्गीकृत (`data/questions.json`)।
- **आधा निःशुल्क** — विश्लेषण र अभ्यासको पहिलो आधा भाग निःशुल्क; बाँकीमा *"कृपया भुक्तानी गरी अगाडि बढ्नुहोस्"*।
- **भुक्तानी** — eSewa, Khalti; वा **गोप्य प्रोमो कोड** (तपाईंले निश्चित प्रयोगकर्तालाई मात्र दिने)।
- **मोडेल सेट** — पहिलो सेट निःशुल्क; त्यसपछि **रु २५/सेट** वा पूर्ण पहुँच **रु १०००**।
- **रफ पेपर** — मोबाइलमा Samsung Notes झैँ हातले लेख्न मिल्ने क्यानभास (कलम/रबर/रङ)।
- **नतिजा** — रोल नम्बर, स्कोर रिङ, सही/गलत/छोडिएको र **२०% ऋणात्मक अंक**सहित पूर्ण गणना; उत्तरसहित समीक्षा।

## 🔑 गोप्य प्रोमो कोड (Secret unlock codes)

कोडहरू वेबसाइटमा **कतै देखाइँदैन** — तपाईंले चाहेका निश्चित प्रयोगकर्तालाई मात्र निजी रूपमा दिनुहोस्।
सम्पादन गर्ने ठाउँ: **`public/js/core.js` को माथिल्लो भाग** —

```js
const PROMO_CODES = ['SL-VIP-2026', 'TOPPER-500'];
```

- फरक व्यक्तिलाई **फरक कोड** दिन array मा थप्नुहोस् (जस्तै कसैलाई `RAMESH-2026`)।
- कुनै व्यक्तिको पहुँच बन्द गर्न त्यो कोड array बाट **हटाउनुहोस्**।
- कोड ठूला अक्षरमा लेख्नुहोस्; प्रयोगकर्ताले सानो/ठूला जसरी टाइप गरे पनि मिल्छ।
- ⚠️ यी कोड कुनै सार्वजनिक पृष्ठ, स्क्रिनसट वा विज्ञापनमा नराख्नुहोस् — नत्र सबैले निःशुल्क खोल्छन्।

## भुक्तानी सेटअप (Production)

**eSewa र Khalti** लाई वास्तविक (live) बनाउन:

1. `public/js/core.js` को `PAY_CFG` मा आफ्नो merchant credentials राख्नुहोस्:
   - eSewa: `scd` (merchant code) र उत्पादन URL।
   - Khalti: live `publicKey` (र `test.html`/पृष्ठमा Khalti checkout स्क्रिप्ट `<script src="https://khalti.com/static/khalti-checkout.js">` थप्नुहोस्)।
2. **सर्भर-साइड verification** थप्नुहोस् — भुक्तानी सफल भएपछि transaction verify गर्ने endpoint बनाउनुहोस्, अनि मात्र पहुँच दिनुहोस्। (अहिले access `localStorage` मा राखिन्छ, जुन डेमोका लागि हो।)

> हालको कोडमा eSewa को UAT (परीक्षण) endpoint र Khalti को test key राखिएको छ — उत्पादनमा जानुअघि माथिका २ चरण अनिवार्य।

## डाटा थप्ने/सम्पादन गर्ने

- **प्रश्न थप्न** — `data/questions.json` को `questions` array मा नयाँ object थप्नुहोस् (`unit`, `part`, `type`, `qn`, `qe`, `opt`, `ans`, `exp`)।
- **सेट बनाउन** — `data/sets.json` मा `qids` (प्रश्न id हरू) सहित नयाँ सेट थप्नुहोस्।
- **विश्लेषण अपडेट** — `data/syllabus.json` सम्पादन गर्नुहोस्।
